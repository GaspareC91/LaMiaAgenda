# La mia agenda v0.5.5

Modifiche rispetto alla v0.5.4:
- il pulsante Oggi della schermata principale assume la funzione di accesso agli Studi, mantenendo forma, colore e posizione del precedente pulsante Studi; il vecchio pulsante Studi viene rimosso;
- il pulsante Prestazioni diventa Prestazioni di oggi;
- aggiunto il pulsante per tornare alla schermata principale da Riepiloghi;
- nei campi data il cursore viene spostato automaticamente dopo il trattino quando si trova immediatamente prima di "-";
- aggiunto il tipo di compenso Fisso a prestazione;
- per Fisso a prestazione il Prezzo viene impostato automaticamente a 0 e resta visibile;
- per gli accordi A percentuale, selezionando una prestazione suggerita viene proposto il prezzo storico più frequente per studio e prestazione e viene calcolato il guadagno secondo la percentuale concordata;
- per Fisso a prestazione, selezionando una prestazione suggerita viene proposto il guadagno storico più frequente per studio e prestazione;
- le proposte storiche restano modificabili.
